# DUBAI FANS AI: مساعد التسويق الرقمي

مساعد تسويق بالعربية لعلامة **DUBAI FANS**، يعمل داخل ChatGPT وClaude وGemini. يكتب الخطط والمنشورات والكاروسيل وسكريبتات الريلز وإعلانات المنصات، ويلتزم بملف الهوية، ولا ينشر بدون موافقتك.

## ما في هذا المجلد

| الملف | وظيفته |
| --- | --- |
| `brand-profile.md` | ملف الهوية: الجمهور، النبرة، الألوان، العروض، الهاشتاقات. **املأه أولًا.** |
| `core-instructions.md` | المصدر الواحد لتعليمات المساعد: القواعد، الممنوعات، صيغة الرد، قائمة الفحص. |
| `chatgpt/custom-gpt.md` | خطوات إنشاء Custom GPT في ChatGPT، والحقول الجاهزة للنسخ. |
| `claude/dubai-fans-marketing/` | Claude Skill: مجلد جاهز يحتوي `SKILL.md` و`brand-profile.md` و`core-instructions.md`. |
| `gemini/gem.md` | خطوات إنشاء Gem في Gemini، والحقول الجاهزة للنسخ. |

## التثبيت

### 1. املأ ملف الهوية

افتح `brand-profile.md` واملأ الخانات. الخانة الفارغة تعني أن المساعد سيسألك عنها أو يفترض افتراضًا ويعلنه. لا تضع فيه كلمات مرور أو مفاتيح API أو بيانات شخصية.

### 2. ثبّته على المنصة التي تستخدمها

| المنصة | الطريقة | الملف المطلوب |
| --- | --- | --- |
| ChatGPT | Custom GPT، وارفع الملف في Knowledge | `chatgpt/custom-gpt.md` |
| Claude | ارفع مجلد `claude/dubai-fans-marketing/` كـ Skill من إعدادات Claude (Skills) | مجلد الـ Skill |
| Gemini | أنشئ Gem والصق التعليمات | `gemini/gem.md` |

### 3. جرّبه

استخدم أول ثلاث رسائل من قائمة **Conversation starters** في الدليل، وراجع أول رد بقائمة الفحص الموجودة في `core-instructions.md`.

## تعديل التعليمات

المصدر الواحد هو `core-instructions.md`. عند أي تعديل:

1. عدّل `core-instructions.md` أولًا.
2. انسخ التعديل إلى Custom GPT وGem.
3. حدّث نسخة الـ Skill في `claude/dubai-fans-marketing/core-instructions.md`.

## حدود معروفة

- **لا تحقق من الحقائق تلقائيًا.** المساعد لا يتحقق من أرقام العروض أو المواعيد أو القوانين. المراجعة البشرية قبل النشر إلزامية.
- **المحتوى المنظم قانونيًا** (صحة، مال، عقارات، مسابقات، إعلانات الأطفال) يحتاج مراجعة مختص قبل النشر. المساعد ينبّه لذلك لكنه لا يحل محل المراجعة.
- **النشر المباشر** غير مضمون عبر هذا الدليل. ربط Adly لـ ChatGPT اختياري ولم يُختبر مع حسابات DUBAI FANS.
- **الحدود الطويلة**: بعض المنصات تحدد طول حقل التعليمات. إذا رُفضت التعليمات لطولها، انقل التفاصيل الثانوية إلى ملف Knowledge.
- **الأعياد والمواسم** تتغير مواعيدها كل سنة. المساعد يُفترض أن يتحقق منها، لكن راجعها بنفسك.
