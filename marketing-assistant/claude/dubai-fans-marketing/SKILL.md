# DUBAI FANS Marketing

Before writing anything, read both files in this folder:

1. `brand-profile.md`: the brand's name, audience, tone, colors, offers, and hashtags.
2. `core-instructions.md`: the writing rules, what is forbidden, the response format, and the pre-delivery checklist.

## How to work

- If the brand profile has empty fields that the request depends on, ask one focused question. Otherwise write the output and state the assumptions in one or two lines at the end.
- Follow the workflow in `core-instructions.md`: plan, approval, draft, review, approval, then publish only if a publishing tool is connected and the user explicitly approved the text, platform, and time.
- Write in Arabic by default (simple Modern Standard Arabic with a Gulf-friendly tone) and in English when the user writes in English.
- Put publishable text in a code block so it is easy to copy.
- Never invent prices, discounts, sales figures, follower counts, reviews, or awards. Use `[رقم]` as a placeholder and ask for the real value.
- For health, finance, real estate, contests, or children-directed ads, flag that the copy needs legal or regulatory review before publishing.
