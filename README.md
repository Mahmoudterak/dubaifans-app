# MT Reels AI

مساعد كتابة سكريبتات الريلز لحساب **محمود طارق** (استشاري نفسي متخصص في العلاقات وتطوير الذات).

الفكرة مش مولّد نصوص عام. الأداة بتاخد موضوع أو سؤال متابع أو موقف، وتطلع منه:
3 افتتاحيات مع ترشيح الأقوى، وسكريبت منطوق بلهجة مصرية بسيطة، وتقسيم زمني للمشاهد، وغلاف وكابشن وCTA هادي وسؤال للتعليقات، ومراجعة جودة نفسية قبل ما تعرض النتيجة.

## الحالة الحالية

| المجال | الحالة |
| --- | --- |
| توليد السكريبت (10 أوضاع، 3 افتتاحيات، 12 مخرجًا) | مكتمل |
| التعديل بأزرار جاهزة أو تعليمة حرة، وتغيير الافتتاحية فقط | مكتمل |
| سجل الإصدارات (لا يُحذف أي إصدار، ويمكن استعادة أي نسخة) | مكتمل |
| حفظ، فلترة، بحث، وحذف السكريبتات | مكتمل |
| مكتبة الموضوعات والتصنيفات (قابلة للتوسعة من الواجهة) | مكتمل |
| أسلوب الكتابة و«اكتب بطريقتي» (عينات كلامك) | مكتمل |
| مراجعة الجودة الداخلية وتقييم السكريبتات | مكتمل |
| تقويم المحتوى (إضافة، تعديل الحالة، حذف) | مكتمل، بدون نشر تلقائي على المنصات |
| تحليل أداء الريلز بالمشاهدات والتفاعل | **لم يُنفَّذ** (الخطوة الثانية حسب خطة المنتج) |
| حساب مستخدمين متعدد | **لم يُنفَّذ**: التطبيق لحساب مالك واحد، والجداول جاهزة بـ `user_id` للتوسعة |

## المتطلبات

- Node.js 20.9 أو أحدث
- PostgreSQL 14 أو أحدث (Neon أو Supabase أو Vercel Postgres أو محلي)
- مفتاح API من مزود نماذج: Anthropic أو OpenAI أو أي خدمة متوافقة مع واجهة OpenAI

## الإعداد المحلي

```bash
npm install
cp .env.example .env.local   # ثم املأ القيم
npm run db:migrate            # ينشئ الجداول ويزرع التصنيفات
npm run dev                   # http://localhost:3000
```

### متغيرات البيئة

الأسماء كاملة في `.env.example`. القيم الحقيقية لا تُكتب في الكود ولا تُرفع للمستودع.

| المتغير | مطلوب | الوصف |
| --- | --- | --- |
| `DATABASE_URL` | نعم | رابط PostgreSQL |
| `APP_PASSWORD` | نعم في الإنتاج | كلمة مرور دخول التطبيق |
| `APP_SESSION_SECRET` | نعم مع `APP_PASSWORD` | سر توقيع الجلسة، 16 حرفًا على الأقل |
| `AI_PROVIDER` | نعم للتوليد | `anthropic` أو `openai` |
| `AI_API_KEY` | نعم للتوليد | مفتاح المزود، يُقرأ على الخادم فقط |
| `AI_MODEL` | نعم للتوليد | اسم النموذج الذي تختاره (ما فيش نموذج افتراضي) |
| `AI_BASE_URL` | لا | لخدمة متوافقة مع OpenAI |
| `AI_TIMEOUT_MS` | لا | المهلة بالمللي ثانية، الافتراضي 60000 |
| `GENERATION_RATE_LIMIT_PER_HOUR` | لا | حد التوليد في الساعة، الافتراضي 30 |
| `OWNER_EMAIL`, `OWNER_DISPLAY_NAME` | لا | بيانات حساب المالك |

لو متغيرات المزود ناقصة، التطبيق يفتح عادي، لكن زر التوليد يتعطل ويعرض أسماء المتغيرات الناقصة. صفحة **النموذج** في التطبيق بتعرض الحالة دي.

> الحالة بتتأكد من وجود المتغيرات فقط. الاتصال الفعلي بالمزود بيتأكد عند أول توليد، لأن التطبيق ما بيبعتش طلبات تجريبية.

## الاختبارات

```bash
npm run typecheck     # فحص الأنواع
npm run lint          # ESLint (Next + TypeScript)
npm test              # اختبارات الوحدات (تعمل بدون قاعدة بيانات)
```

اختبارات التكامل على PostgreSQL حقيقي تعمل فقط لو ضبطت `TEST_DATABASE_URL` على **قاعدة اختبار منفصلة**، لأنها تمسح بيانات المستخدمين قبل البدء:

```bash
TEST_DATABASE_URL=postgres://... npm test
```

الاختبارات تغطي: مدة الإلقاء والتشكيل العربي، مخطط مخرجات النموذج، مراجعة الجودة، بناء الـ prompts، إعادة الطلب عند مخرجات غير صالحة، المهلات، أخطاء المزود، تحديد المعدل، الدخول، وفصل بيانات المستخدمين والإصدارات في قاعدة حقيقية.

## النشر على Vercel

1. ارفع المستودع واربطه بمشروع Vercel.
2. أضف متغيرات البيئة من الجدول فوق في **Project Settings → Environment Variables**.
3. شغّل الترحيلات مرة على قاعدة الإنتاج من جهازك: `DATABASE_URL=... npm run db:migrate`. الترحيلات ما بتشتغلش تلقائيًا أثناء البناء، وكل ملف فيه بيتطبق مرة واحدة ويتسجل في `schema_migrations`.
4. انشر. لو `APP_PASSWORD` أو `APP_SESSION_SECRET` ناقصين في الإنتاج، التطبيق بيقفل ويعرض رسالة الإعداد بدل ما يفتح بدون حماية.

## بنية المشروع

```
app/                  صفحات App Router (RTL عربي) ومسارات الـ API
  api/                مسارات JSON: scripts, topics, calendar, preferences, auth, status
components/           مكونات الواجهة، ومحرر السكريبت، ونموذج التوليد
lib/
  ai/                 مزودات النماذج (Anthropic و OpenAI-compatible) وقراءة الإعداد
  script/             الأوضاع والمدد، المخطط الصارم للمخرجات، الـ prompts، مراجعة الجودة
  services/           منطق التوليد والحفظ والتعديل والإصدارات
  repo/               استعلامات SQL لكل جدول
  auth/, proxy.ts     بوابة الدخول بكلمة مرور وجلسة موقّعة
db/migrations/        ملفات SQL مرقّمة (001 المخطط، 002 بذور التصنيفات)
scripts/migrate.ts    تشغيل الترحيلات
tests/                اختبارات الوحدات والتكامل
```

### نموذج البيانات

`users` · `user_preferences` · `topic_categories` · `topics` · `scripts` · `script_versions` · `script_feedback` · `content_calendar`

كل سكريبت يحمل نسخته الحالية في `scripts.content` (JSON)، وكل تعديل يضيف صفًا جديدًا في `script_versions`. النسخ القديمة لا تُعدَّل ولا تُحذف إلا مع حذف السكريبت نفسه.

## الأمان

- المفاتيح تُقرأ من البيئة على الخادم فقط، ولا تظهر في أي استجابة أو صفحة. اختبار حالة الإعداد يتأكد أن المفتاح لا يدخل الرد، والتحقق من الصفحات تم يدويًا على خادم الإنتاج المحلي.
- كل مدخل يمر بمخطط zod قبل أي استخدام، وكل مخرج من النموذج يمر بمخطط صارم قبل الحفظ.
- النموذج يُطلب منه JSON فقط، ولو رجع صيغة غير صالحة يُعاد الطلب مرة واحدة بتوضيح السبب، ثم يُرفض الرد برسالة عربية.
- المهلة على كل طلب للمزود، وأخطاء المزود لا تكشف تفاصيله الخام للمستخدم.
- الدخول بكلمة مرور من البيئة، والكوكي موقّع بـ HMAC ومحمي بـ `httpOnly` و`SameSite=Lax`، و`Secure` على HTTPS. محاولات الدخول محدودة بـ 10 كل 15 دقيقة لكل عنوان.
- بيانات المستخدم (السكريبتات والإصدارات والتقييمات والتقويم والموضوعات الخاصة والتفضيلات) مقيّدة بـ `user_id` للمستخدم الحالي. جدول تصنيفات الموضوعات عام بالتصميم.

## قيود معروفة (ومقصودة في هذه النسخة)

- **تحديد المعدل في الذاكرة**: عداد التوليد يعمل لكل نسخة خادم، وعلى Vercel ممكن يختلف بين النسخ. للحماية الصارمة للتكلفة استخدم مخزنًا مشتركًا مثل Redis.
- **مراجعة الجودة قواعد وليست حكمًا**: بتلتقط الوعود الزائفة، والتشخيص بالاسم، والتعميم، والأرقام والدراسات المذكورة بدون مصدر، والتهويل، والمدة. لكنها ما تحل محل قراءتك للنص بصوت عالي قبل النشر.
- **ما فيش تحقق تلقائي من الدراسات أو الأرقام**: الأداة بتحذرك لو ظهرت، ولا تتأكد من صحتها.
- **مكتبة الموضوعات مش بتتحقق من تكرار الزوايا تلقائيًا**: التطبيق بيمرر آخر 10 افتتاحيات للنموذج كـ«ممنوع تكرارها»، لكن التشابه الدلالي غير مقاس.
- **التقويم بدون نشر تلقائي**: ما فيش ربط بـ Instagram أو TikTok أو غيرهم.
